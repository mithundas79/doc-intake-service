## Delivered scope and limitations

Implementation, startup docs, walkthrough, evaluation, samples, CI and draft PR are delivered. Full required hosted verification passed at the recorded application code checkpoint. The separate guided-preview follow-up is described below. No multi-user/production readiness claim is made. Windows lacks the POSIX1.5GiB decoder address-space cap; it still has input/page/pixel/text/time limits. Extraction/classification are English-first heuristics. Mixed text/image PDF pages with an existing substantial text layer do not OCR additional image regions. Manual documents without number/total use byte identity only. Audit is durable, not tamper-proof against local filesystem access. Old demo audit.jsonl data is not automatically migrated.
